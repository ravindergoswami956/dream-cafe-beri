## ✨ Features

- 🍔 **Interactive 3D Food Studio**: Real-time 360° interactive 3D burger model built with Three.js.
- 📜 **Complete Digital Menu**: Artisan pizzas, crispy burgers, pastas, sandwiches, momos, fries, and shakes with instant category filters and search.
- 🔐 **Owner Admin Dashboard**: Secure password-protected dashboard allowing the cafe owner to add/edit/delete dishes, update prices, and modify timings.
- 📍 **Location & Quick Contact**: One-tap phone calling, WhatsApp ordering, and Google Maps directions to Lala Ram Sarup Memorial Park, Beri.
- 📱 **100% Mobile Responsive**: Polished for iPhones, Android smartphones, tablets, and desktop computers.
